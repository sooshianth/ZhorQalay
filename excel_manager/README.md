# قابلیت ویرایش برخط فایل‌های اکسل

این ماژول امکان ویرایش لایو (برخط) فایل‌های اکسل را فراهم می‌کند. کاربران می‌توانند مستقیماً در مرورگر با قابلیت‌های زیر اقدام به ویرایش فایل‌های اکسل نمایند:

## قابلیت‌های اصلی

- **ویرایش سلول‌ها**: با کلیک روی هر سلول، امکان ویرایش محتوای آن فراهم می‌شود.
- **حذف سطر**: امکان حذف سطرهای جدول با کلیک روی آیکون سطل زباله.
- **اضافه کردن سطر**: امکان اضافه کردن سطر جدید به انتهای جدول.
- **ذخیره تغییرات**: با کلیک دکمه ذخیره، تمامی تغییرات در فایل اصلی ذخیره می‌شود.

## نحوه کارکرد

این سیستم از ترکیب DataTables برای نمایش جدول و AJAX برای ارسال تغییرات به سرور استفاده می‌کند. پس از اعمال تغییرات، فایل اکسل اصلی به‌روزرسانی می‌شود.

برای فایل‌های HTML (مانند خروجی بازارگاه)، سیستم محتوای HTML را به‌روزرسانی کرده و فایل را با حفظ استایل‌ها ذخیره می‌کند.

## پشتیبانی از انواع فایل‌ها

- فایل‌های اکسل معمولی (.xlsx)
- فایل‌های اکسل قدیمی (.xls)
- فایل‌های HTML حاوی جدول (مانند خروجی بازارگاه)

## نکات مهم

1. قبل از ذخیره، یک نسخه پشتیبان (با پسوند .bak) از فایل ایجاد می‌شود.
2. تمام تغییرات در لاگ سیستم ثبت می‌شود.
3. تغییرات تنها پس از کلیک دکمه ذخیره اعمال می‌شوند.
