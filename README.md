# کانقالای - سیستم مدیریت منابع سازمانی و ارتباط با مشتری

## معرفی
کانقالای یک سیستم مدیریت منابع سازمانی (ERP) و مدیریت ارتباط با مشتری (CRM) است که با استفاده از فریم‌ورک Django پیاده‌سازی شده است. این سیستم امکاناتی از جمله مدیریت مشتریان، مدیریت فروش، مدیریت محصولات، ارسال پیامک و پیام‌های واتساپ را فراهم می‌کند.

## قابلیت‌های کلیدی
- مدیریت مشتریان (CRM)
- مدیریت منابع سازمانی (ERP)
- سیستم پیامک و ارتباط با مشتری
- سیستم پیام‌رسانی واتساپ
- مدیریت فروش و سفارش‌ها
- مدیریت محصولات
- گزارش‌گیری و داشبورد مدیریتی

## تکنولوژی‌های استفاده شده
- Django: فریم‌ورک اصلی توسعه وب
- Django Channels: برای ارتباطات WebSocket و ASGI
- Celery: برای مدیریت وظایف غیرهمزمان و زمان‌بندی شده
- Redis: به عنوان broker برای Celery و سیستم کش
- SQLite: پایگاه داده اصلی سیستم
- Django REST Framework: برای توسعه APIs

## نصب و راه‌اندازی
برای نصب و راه‌اندازی پروژه، به مستندات بخش نصب در پوشه `/docs` مراجعه کنید یا مراحل زیر را دنبال کنید:

1. کلون کردن مخزن:
```bash
git clone https://github.com/yourusername/kunqalay.git
cd kunqalay
```

2. ایجاد محیط مجازی:
```bash
python -m venv venv
# در ویندوز
venv\Scripts\activate
# در لینوکس/مک
source venv/bin/activate
```

3. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

4. اجرای مهاجرت‌های پایگاه داده:
```bash
python manage.py migrate
```

5. ایجاد کاربر مدیر:
```bash
python manage.py createsuperuser
```

6. اجرای سرور توسعه:
```bash
python manage.py runserver
```

7. اجرای Celery:
```bash
celery -A config worker -l info
```

8. اجرای Celery Beat:
```bash
celery -A config beat -l info
```

## مستندات
پروژه دارای مستندات کاملی است که در پوشه `/docs` قرار دارد. برای ساخت و مشاهده مستندات، مراحل زیر را دنبال کنید:

1. نصب نیازمندی‌های مستندسازی:
```bash
pip install sphinx sphinx-rtd-theme django-sphinx-autodoc
```

2. ساخت مستندات:
```bash
cd docs
python makedocs.py html
```

3. مشاهده مستندات:
```bash
# در ویندوز
start build/html/index.html
# در لینوکس
xdg-open build/html/index.html
# در مک
open build/html/index.html
```

برای اطلاعات بیشتر درباره مستندات، به فایل `docs/README.md` مراجعه کنید.

## ساختار پروژه
- `config/`: تنظیمات اصلی پروژه
- `core/`: ماژول اصلی سیستم که مدل‌های پایه و کلاس‌های مشترک را تعریف می‌کند
- `CRM/`: ماژول مدیریت ارتباط با مشتری
- `ERP/`: ماژول مدیریت منابع سازمانی
- `sales/`: ماژول مدیریت فروش
- `sms_api/`: ماژول ارسال و دریافت پیامک
- `whatsapp_api/`: ماژول ارسال و دریافت پیام در واتساپ
- `excel_manager/`: ماژول مدیریت فایل‌های اکسل و گزارش‌گیری
- `chat/`: ماژول سیستم گفتگوی داخلی
- `docs/`: مستندات پروژه
