ماژول Core
========

ماژول Core هسته اصلی سیستم کانقالای است که مدل‌های پایه و کلاس‌های مشترک مورد استفاده در سایر ماژول‌ها را تعریف می‌کند.

مدل‌های اصلی
---------

مدل Customer
~~~~~~~~~

مدل Customer برای نگهداری اطلاعات مشتریان طراحی شده است.

**فیلدهای اصلی**:

* **phone_number**: شماره تلفن مشتری (در حال منسوخ شدن)
* **sales_agent**: ارتباط چند به چند با کارشناسان فروش
* **name**: نام مشتری
* **city**: شهر مشتری
* **whatsapp_preference**: ترجیح استفاده از واتساپ
* **field_of_activity**: حیطه فعالیت مشتری
* **purchase_preferences**: ترجیحات پرداخت
* **product_preferences**: ترجیحات کالایی
* **contact_start_time**: زمان شروع تماس
* **contact_end_time**: زمان پایان تماس
* **social_media**: اطلاعات شبکه‌های اجتماعی
* **added_description**: توضیحات تکمیلی
* **sms_preference**: ترجیح دریافت پیامک
* **day_of_week**: روز هفته برای ارسال پیام
* **quota**: سهمیه
* **created_at**: تاریخ ثبت
* **updated_at**: تاریخ بروزرسانی
* **is_bazaargah_enjoyer**: استفاده از بازارگاه

**متدهای اصلی**:

* **get_customer_by_phone**: یافتن مشتری بر اساس شماره تلفن
* **get_primary_phone**: دریافت شماره تلفن اصلی
* **get_all_phone_numbers**: دریافت تمام شماره‌های تلفن
* **get_tasks_by_time**: دریافت وظایف مرتبط با مشتری بر اساس زمان
* **get_calls_by_time**: دریافت تماس‌های مرتبط با مشتری بر اساس زمان
* **get_purchases_by_time**: دریافت خریدهای مشتری بر اساس زمان
* **get_field_of_activity_display**: نمایش حیطه فعالیت مشتری
* **get_field_of_activity_list**: دریافت لیست حیطه‌های فعالیت
* **set_field_of_activity_list**: تنظیم لیست حیطه‌های فعالیت

مدل SalesAgent
~~~~~~~~~~~~

مدل SalesAgent برای نگهداری اطلاعات کارشناسان فروش طراحی شده است.

**فیلدهای اصلی**:

* **user**: ارتباط یک به یک با مدل User
* **name**: نام کارشناس فروش
* **email**: ایمیل کارشناس فروش
* **phone**: شماره تلفن کارشناس فروش
* **created_at**: تاریخ ثبت
* **updated_at**: تاریخ بروزرسانی

**متدهای اصلی**:

* **get_customers**: دریافت مشتریان مرتبط با کارشناس فروش
* **get_tasks**: دریافت وظایف مرتبط با کارشناس فروش
* **get_calls**: دریافت تماس‌های مرتبط با کارشناس فروش
* **get_purchases**: دریافت خریدهای مرتبط با کارشناس فروش

مدل CargoProduct
~~~~~~~~~~~~~

مدل CargoProduct برای نگهداری اطلاعات محصولات طراحی شده است.

**فیلدهای اصلی**:

* **product_name**: نام محصول
* **product_type**: نوع محصول
* **brand**: برند محصول
* **model**: مدل محصول
* **origin**: مبدا محصول
* **volume**: حجم محصول
* **weight**: وزن محصول
* **description**: توضیحات محصول
* **barcode**: بارکد محصول
* **created_at**: تاریخ ثبت
* **updated_at**: تاریخ بروزرسانی

مدل PurchaseModel
~~~~~~~~~~~~~~

مدل PurchaseModel برای نگهداری اطلاعات خریدها طراحی شده است.

**فیلدهای اصلی**:

* **customer**: ارتباط با مشتری
* **sales_agent**: ارتباط با کارشناس فروش
* **product**: ارتباط با محصول
* **quantity**: تعداد
* **price**: قیمت
* **total_price**: قیمت کل
* **purchase_date**: تاریخ خرید
* **status**: وضعیت خرید
* **payment_method**: روش پرداخت
* **created_at**: تاریخ ثبت
* **updated_at**: تاریخ بروزرسانی

مدل TaskModel
~~~~~~~~~~

مدل TaskModel برای نگهداری اطلاعات وظایف طراحی شده است.

**فیلدهای اصلی**:

* **title**: عنوان وظیفه
* **description**: توضیحات وظیفه
* **assigned_to**: ارتباط با کاربر مسئول
* **customer**: ارتباط با مشتری
* **due_date**: تاریخ سررسید
* **status**: وضعیت وظیفه
* **priority**: اولویت وظیفه
* **created_at**: تاریخ ثبت
* **updated_at**: تاریخ بروزرسانی

مدل NotificationModel
~~~~~~~~~~~~~~~~~

مدل NotificationModel برای نگهداری اطلاعات اعلان‌ها طراحی شده است.

**فیلدهای اصلی**:

* **user**: ارتباط با کاربر
* **title**: عنوان اعلان
* **message**: متن اعلان
* **type**: نوع اعلان
* **read**: خوانده شده/نشده
* **created_at**: تاریخ ثبت

فرم‌ها
-----

در ماژول Core، فرم‌های مختلفی برای کار با مدل‌های فوق تعریف شده‌اند، از جمله:

* **CustomerForm**: فرم ایجاد و ویرایش مشتری
* **SalesAgentForm**: فرم ایجاد و ویرایش کارشناس فروش
* **ProductForm**: فرم ایجاد و ویرایش محصول
* **PurchaseForm**: فرم ایجاد و ویرایش خرید
* **TaskForm**: فرم ایجاد و ویرایش وظیفه

میان‌افزارها
---------

ماژول Core شامل چندین میان‌افزار (Middleware) است که وظایف مختلفی را انجام می‌دهند:

* **SessionTimeoutMiddleware**: میان‌افزار مدیریت زمان‌سنجی نشست کاربر
* **AuthenticationMiddleware**: میان‌افزار احراز هویت کاربر

دکوراتورها
--------

ماژول Core شامل چندین دکوراتور است که برای مدیریت دسترسی و کنترل رفتار توابع view طراحی شده‌اند:

* **login_required**: بررسی لاگین بودن کاربر
* **permission_required**: بررسی دسترسی‌های کاربر
* **sales_agent_required**: بررسی کارشناس فروش بودن کاربر
