# اپلیکیشن پیش‌فاکتور (Proforma Invoice)

## نسخه 2.0 - بروزرسانی جامع

### 📋 خلاصه تغییرات

این اپلیکیشن برای صدور و مدیریت پیش‌فاکتورهای شرکت طراحی شده است. در نسخه جدید، امکانات زیادی اضافه شده است:

### ✨ ویژگی‌های جدید

#### 1. **داشبورد مدیر مالی**
- صفحه اختصاصی برای مدیران مالی جهت مدیریت پیش‌فاکتورها
- جستجوی پیشرفته با Autocomplete برای یافتن سریع مشتریان
- امکان ویرایش اطلاعات فاکتوری مشتری (کد ملی، آدرس، کد پستی و...)
- نمایش لیست پیش‌فاکتورهای هر مشتری

#### 2. **تخفیف و ملاحظات محصول**
- امکان تعیین درصد تخفیف برای هر محصول
- نمایش خودکار مبلغ بعد از تخفیف
- فیلد ملاحظات اختصاصی برای هر محصول
- محاسبه خودکار قیمت نهایی با در نظر گرفتن تخفیف

#### 3. **بهینه‌سازی PDF**
- کاهش اندازه فونت‌ها و فضاها برای جا شدن در یک صفحه A4
- انتقال اطلاعات حساب بانکی به بخش ملاحظات (به جای کادر جداگانه)
- بهبود استایل و قالب‌بندی برای خوانایی بهتر

#### 4. **محدودیت دسترسی**
- استفاده از دکوراتور `@role_required` برای کنترل دسترسی
- دسترسی‌ها:
  - کارشناس فروش: ایجاد و مدیریت پیش‌فاکتورهای خود
  - مدیر مالی: دسترسی کامل به تمام پیش‌فاکتورها و ویرایش اطلاعات فاکتوری
  - ادمین: دسترسی کامل به همه بخش‌ها

#### 5. **لاگ‌گذاری جامع**
- ثبت تمام فعالیت‌های مهم در فایل لاگ
- جداسازی لاگ‌های پیش‌فاکتور از سایر بخش‌ها
- امکان پیگیری مشکلات و رفع خطا

### 🔧 تنظیمات اولیه

#### 1. اضافه کردن به INSTALLED_APPS

در فایل `settings.py`:

```python
INSTALLED_APPS = [
    # ...
    'proforma_invoice',
    # ...
]
```

#### 2. اضافه کردن URLها

در فایل `urls.py` اصلی پروژه:

```python
from django.urls import path, include

urlpatterns = [
    # ...
    path('proforma/', include('proforma_invoice.urls')),
    # ...
]
```

#### 3. تنظیمات لاگ‌گذاری

محتوای فایل `config/logging_settings_template.py` را به `settings.py` اضافه کنید.

#### 4. اجرای Migration

```bash
python manage.py migrate proforma_invoice
```

#### 5. ایجاد اطلاعات شرکت

از پنل مدیریت Django یک رکورد `CompanyInfo` ایجاد کنید و آن را فعال (is_active=True) کنید.

### 🚀 نحوه استفاده

#### برای کارشناس فروش:

1. وارد صفحه مشتری شوید (از طریق مدیریت مشتریان)
2. روی دکمه "صدور پیش‌فاکتور" کلیک کنید
3. اطلاعات مشتری را بررسی و تایید کنید
4. محصولات مورد نظر را اضافه کنید (با قابلیت تخفیف و ملاحظات)
5. پیش‌نمایش را بررسی کنید
6. پیش‌فاکتور را نهایی کنید و PDF دانلود کنید

#### برای مدیر مالی:

1. از منوی سایدبار، وارد "داشبورد پیش‌فاکتور" شوید
2. مشتری مورد نظر را جستجو کنید
3. اطلاعات فاکتوری را ویرایش و ذخیره کنید
4. در صورت نیاز، پیش‌فاکتور جدید صادر کنید
5. پیش‌فاکتورهای قبلی را مشاهده و دانلود کنید

### 📊 مدل‌های داده

#### CompanyInfo
اطلاعات شرکت برای نمایش در پیش‌فاکتور:
- نام شرکت، شناسه ملی، کد اقتصادی
- اطلاعات تماس (تلفن، ایمیل، وبسایت)
- آدرس و کد پستی
- اطلاعات بانکی (شماره حساب، شبا، کارت)
- لوگو و امضا

#### ProformaInvoice
پیش‌فاکتور اصلی:
- شماره یکتای پیش‌فاکتور (فرمت: PI-YYMMDD-XXX)
- مشتری و کارشناس فروش
- تاریخ صدور و تاریخ اعتبار
- قیمت کل (محاسبه خودکار)
- ملاحظات
- وضعیت نهایی شده/پیش‌نویس

#### ProformaInvoiceItem
آیتم‌های پیش‌فاکتور (محصولات):
- نام و توضیحات محصول
- مقدار و واحد (کیلوگرم، تن، کیسه)
- قیمت واحد
- **درصد تخفیف (جدید)**
- **ملاحظات محصول (جدید)**
- ترتیب نمایش

### 🐛 عیب‌یابی

#### مشکلات رایج:

1. **خطای WeasyPrint**
   - مطمئن شوید پکیج WeasyPrint نصب شده: `pip install weasyprint`
   - در Windows باید GTK+ نصب باشد

2. **خطای فونت فارسی در PDF**
   - اتصال به اینترنت را بررسی کنید (فونت از CDN دریافت می‌شود)
   - یا فایل فونت را به صورت محلی در پروژه قرار دهید

3. **مشکل در محاسبه تخفیف**
   - مقدار تخفیف باید بین 0 تا 100 باشد
   - JavaScript را در مرورگر فعال کنید
