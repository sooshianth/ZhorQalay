# SMS Queue System

یک سیستم برای ذخیره و ارسال دوره‌ای پیامک‌ها

## ویژگی‌ها

- ذخیره پیامک‌ها در صف ارسال
- ارسال دوره‌ای پیامک‌ها
- امکان معلق کردن پیامک‌ها و خارج کردن از تعلیق
- امکان زمان‌بندی ارسال پیامک‌ها
- ثبت تاریخچه ارسال پیامک‌ها

## نحوه استفاده

### ارسال پیامک

برای ارسال پیامک، از تابع `queue_sms` در `apis.py` استفاده کنید:

```python
from sms_api.apis import queue_sms

# افزودن پیامک به صف
queue_sms(
    number="09123456789",
    message="متن پیامک",
    notification_type="custom",  # نوع اطلاع‌رسانی
    purchase_id=None,  # شناسه خرید مرتبط (اختیاری)
    suspended=False  # آیا پیامک معلق باشد؟
)
```

### پردازش صف پیامک‌ها

برای پردازش پیامک‌های در انتظار ارسال، از دستور مدیریتی زیر استفاده کنید:

```bash
python manage.py process_sms_queue --batch-size=20
```

می‌توانید این دستور را به صورت دوره‌ای (مثلاً هر 5 دقیقه) با استفاده از cron یا celery اجرا کنید.

### زمان‌بندی پیامک جدید

برای زمان‌بندی پیامک جدید برای ارسال، از دستور مدیریتی زیر استفاده کنید:

```bash
python manage.py schedule_sms "09123456789" "متن پیامک" --delay=30 --type=custom
```

### تلاش مجدد پیامک‌های ناموفق

برای تلاش مجدد ارسال پیامک‌های ناموفق، از دستور مدیریتی زیر استفاده کنید:

```bash
python manage.py retry_failed_sms --max-retries=3
```

## تنظیم ارسال دوره‌ای

### پیکربندی با Celery

این پروژه از Celery برای اجرای دوره‌ای تسک‌های پردازش صف پیامک استفاده می‌کند. تنظیمات زمان‌بندی در فایل `config/celery.py` قرار دارد:

```python
# تسک پردازش صف پیامک هر 5 دقیقه اجرا می‌شود
'process-sms-queue': {
    'task': 'sms_api.tasks.process_sms_queue_task',
    'schedule': crontab(minute='*/5'),  # هر 5 دقیقه
    'args': (20,),  # اندازه هر دسته: 20 پیامک
},

# تسک تلاش مجدد پیامک‌های ناموفق هر ساعت اجرا می‌شود
'retry-failed-sms': {
    'task': 'sms_api.tasks.retry_failed_sms_task',
    'schedule': crontab(hour='*/1'),  # هر 1 ساعت
    'kwargs': {'max_retries': 3, 'batch_size': 20},
},
```

برای تست عملکرد Celery با سیستم پیامک، می‌توانید از دستور زیر استفاده کنید:

```bash
python manage.py shell
```

و سپس کد زیر را اجرا کنید:

```python
from sms_api.tasks import debug_sms_task
debug_sms_task.delay()
```

### اجرای بکگراند Celery

مطمئن شوید که سرویس‌های Celery در حال اجرا هستند:

```bash
# اجرای worker
celery -A config worker -l info

# اجرای زمان‌بندی کننده (scheduler)
celery -A config beat -l info
```

- مشاهده وضعیت پیامک‌ها
