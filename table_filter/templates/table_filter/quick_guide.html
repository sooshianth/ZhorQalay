مرحله 2: ایجاد جدول

    <thead>

            <th class="{% filter_column_class 'id' 'number' %}" {% filter_column_attrs 'id' 'number' 'شناسه' %}>شناسه</th>

نکات مهم

نکات کلیدی:
  • همیشه {% load table_filter_tags %} را در ابتدای template قرار دهید
  • برای هر جدول، ID منحصر به فرد استفاده کنید
  • کلاس column-{field_name} برای هر ستون الزامی است
  • انواع ستون‌ها: text, number, date, status, boolean, choice
  • فیلتر به صورت خودکار نوع ستون‌ها را تشخیص می‌دهد
انواع داده پشتیبانی شده:
  • متن فارسی: کاملاً پشتیبانی می‌شود
  • اعداد فارسی: تبدیل خودکار به انگلیسی
  • تاریخ شمسی: پشتیبانی کامل
  • وضعیت‌ها: با رنگ‌بندی مناسب
