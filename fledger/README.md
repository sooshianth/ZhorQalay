# اپلیکیشن مدیریت کیف پول واردکنندگان (Fledger)

این اپلیکیشن برای مدیریت کیف پول‌های واردکنندگان و پیگیری تراکنش‌های مالی آن‌ها طراحی شده است.

## ویژگی‌ها

### 1. مدیریت کیف پول‌ها
- ایجاد خودکار کیف پول برای هر واردکننده
- محاسبه خودکار موجودی بر اساس خریدها و تراکنش‌ها
- نمایش جزئیات کامل هر کیف پول

### 2. مدیریت تراکنش‌ها
- ثبت انواع تراکنش‌ها (واریز، برداشت، تعدیل)
- سیستم تایید تراکنش‌ها
- ویرایش و حذف تراکنش‌های در انتظار
- پیوست فایل برای تراکنش‌ها

### 3. دفتر کل
- ثبت خودکار خریدها در دفتر کل
- محاسبه بر اساس `wallet_index` (وزن سفارش یا تحویلی)
- همگام‌سازی خودکار با تغییرات خریدها

### 4. بروزرسانی خودکار
- همگام‌سازی خودکار هنگام تغییر خریدها
- شرط `is_address_sent` برای محاسبه
- استفاده از `wallet_index` برای تعیین نوع وزن

## الگوریتم محاسبه

### محاسبه موجودی کیف پول:
```
موجودی = مجموع تراکنش‌های تایید شده - مجموع بدهی‌های خریدها
```

### محاسبه بدهی خرید:
```python
if purchase.is_address_sent == '1':
    if purchase.wallet_index == '0':
        weight = purchase.order_weight
    else:
        weight = purchase.delivered_weight
    
    debt = weight * purchase.company_price
```

## مدیریت از طریق Command Line

### همگام‌سازی کامل:
```bash
python manage.py sync_wallets --create-missing-wallets --recalculate-all
```

### فقط خریدهای آدرس ارسال شده:
```bash
python manage.py sync_wallets --only-address-sent
```

### ایجاد کیف پول‌های ناموجود:
```bash
python manage.py sync_wallets --create-missing-wallets
```

## مدل‌ها

### Wallet
- `varedkonandeh`: رابطه با واردکننده
- `balance`: موجودی محاسبه شده
- `description`: توضیحات

### Transaction
- `wallet`: رابطه با کیف پول
- `transaction_type`: نوع تراکنش (واریز/برداشت/تعدیل)
- `amount`: مبلغ
- `status`: وضعیت (در انتظار/تایید شده/لغو شده)
- `file`: فایل پیوست

### LedgerEntry
- `varedkonandeh`: رابطه با واردکننده
- `purchase`: رابطه با خرید
- `weight`: وزن محاسبه شده
- `total_amount`: مبلغ کل
- `wallet_index_used`: نوع وزن استفاده شده

## سیگنال‌ها

سیستم به صورت خودکار هنگام تغییرات خریدها، کیف پول‌ها را بروزرسانی می‌کند:

- تغییر در خرید → بروزرسانی LedgerEntry → بروزرسانی موجودی کیف پول
- تایید تراکنش → بروزرسانی موجودی کیف پول
- حذف خرید → حذف LedgerEntry → بروزرسانی موجودی کیف پول

## دسترسی‌ها

این اپلیکیشن نیاز به دسترسی‌های زیر دارد:
- `admin`: دسترسی کامل
- `financial_manager`: دسترسی کامل به مدیریت مالی

## نکات مهم

1. فقط خریدهایی که `is_address_sent = '1'` دارند، در محاسبات لحاظ می‌شوند
2. نوع وزن بر اساس `wallet_index` تعیین می‌شود:
   - `'0'`: وزن سفارش (`order_weight`)
   - `'1'`: وزن تحویلی (`delivered_weight`)
3. سیستم به صورت خودکار کیف پول‌ها را با تغییرات خریدها همگام‌سازی می‌کند
